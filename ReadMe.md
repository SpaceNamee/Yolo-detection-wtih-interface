# YOLO Object Detection Application

Застосунок для детектування об'єктів на зображеннях за допомогою моделі YOLO з графічним інтерфейсом користувача.

---

# Можливості

- Завантаження та аналіз окремих зображень;
- Пакетна обробка папок із зображеннями;
- Відображення результатів детектування;
- Регулювання порогу впевненості;
- Збереження результатів;
- Перегляд графіків тренування моделі;
- Підтримка завантаження інших `.pt` моделей.

---

# Системні вимоги

- Windows 10/11, Linux (Ubuntu 20.04+), macOS 11+;
- Python 3.9+;
- Мінімум 4 ГБ RAM;
- Близько 2 ГБ вільного місця на диску;
- GPU з CUDA (необов'язково, але рекомендовано).

# Встановлення

## 1. Клонування або завантаження проєкту

Завантажте проєкт у локальну директорію та переконайтесь, що файл моделі знаходиться у папці `my_model/`.

---

## 2. Автоматичне налаштування

### Windows

```bash
setup.bat
```

### Linux/macOS

```bash
chmod +x setup.sh
./setup.sh
```

Скрипт:

- створить віртуальне середовище `.venv`;
- встановить усі залежності з `requirements.txt`.

---

## 3. Активація віртуального середовища

### Windows

```bash
.venv\Scripts\activate
```

### Linux/macOS

```bash
source .venv/bin/activate
```

# Інтерфейс застосунку

| Елемент | Опис |
|---|---|
| Open Image | Вибір одного зображення |
| Open Folder (batch) | Пакетна обробка папки |
| Run Detection | Запуск детектування |
| Save Result | Збереження результату |
| Training Metrics | Перегляд графіків тренування |
| Load Different Model | Завантаження іншої моделі |
| Confidence | Регулювання порогу впевненості |
| Original / Detection | Перемикання між вкладками |
| Detection Results | Панель статистики |

---

# Типовий сценарій використання

1. Запустіть застосунок:
   ```bash
   python app.py
   ```

2. Натисніть **Open Image**.

3. Оберіть зображення.

4. За потреби змініть значення **Confidence**.

5. Натисніть **Run Detection**.

6. Перегляньте результат.

7. За потреби збережіть результат кнопкою **Save Result**.

---

# Результати пакетної обробки

Після використання функції **Open Folder (batch)** результати зберігаються у:

```text
runs/detect/predict/
```
